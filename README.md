# field-notes

A plain-text workspace an AI agent (Claude Code, Codex, ChatGPT with files) uses to run a job or internship search for you: applications, LinkedIn/email follow-ups, and a tracker.

## Use it

1. Click **Use this template** (or fork / clone) so you have your own private copy.
2. Open the folder in Claude Code (or any agent that reads `AGENTS.md`).
3. Say: **"Set me up."** The agent interviews you, fills `me/`, and then asks what you want to do.

Nothing personal ships in this repo. Keep your copy **private**; it will hold your phone, email and resume facts.
