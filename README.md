# field-notes

Your own AI job-search assistant. It applies to jobs, finds people to reach out to, and handles LinkedIn and email follow-ups. It asks before sending anything.

## Start in 3 steps

1. Click the green **Use this template** button, then **Create a new repository**. Set it to **Private** (it will hold your info).
2. Open it in [Claude Code](https://claude.com/claude-code):
   ```
   git clone <your new repo link> && cd <folder> && claude
   ```
3. Type **`/start`** (or just say "set me up").

It asks a few quick questions (or reads your resume), then gives you a menu:

```
1. Find jobs and fill applications (you click Submit)
2. Find recruiters / engineers to reach out to
3. Follow up with people who haven't replied
4. Help me reply to an email
```

Each time you come back, type `/start` again and it picks up where you left off.

**Safety:** it shows every message before sending, never clicks the final Submit, and never types passwords.
